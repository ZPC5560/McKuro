十一个模块，共用一套数据

账号登录一次，所有页面都读同一份本地缓存。

  • 启动与更新

    检查更新、可暂停的预下载、边下边更，替换前自动备份。支持修复游戏、跳过校验、下载限速，以及 DX11 / DLSS 启动参数和 DLSS / XeSS 版本检测。

  • 主页总览

    资料卡和每日数据网格：体力、结晶单质、活跃度、周本、终焉矩阵、冥歌海墟、千道门扉、周度游历、电台经验，带回满倒计时。

  • 抽卡分析

    解密本地日志或走云鸣潮接口，按池统计保底、垫抽、歪率和欧气评分。

  • 角色数据

    库街区与 mcguide 双数据源，技能、共鸣链、声骸、属性面板，列表同步后落盘。

  • 深塔与海墟

    逆境深塔、终焉矩阵、海墟统一解析，按轮次展示每队分数，往期历史本地保存。

  • 签到

    多账号一键签到，每日 8:00 自动执行，保留签到统计。

  • 消息提醒

    签到未完成、活动临期、账号失效、周本收尾、活跃度未满，五类各自开关。

  • 兑换码

    远程拉取国服与国际服兑换码，有效的排在前面，点一下复制。

  • 游玩统计

    最近七天逐日时长，加一张 7×24 时段热力格。

  • 活动与资讯

    活动甘特图带今日线，资讯页聚合 wiki、公告和快捷入口。

  • 双语界面

    简体中文和 English 全量切换，包括动态消息和服务层状态。

常见问题

我的账号和抽卡数据会上传吗？

不会。抽卡记录、角色数据和登录凭据只保存在本机，McKuro 没有自己的服务器。它只直连库街区、云鸣潮等官方接口，以及 GitHub 检查更新。

macOS 打开时提示“无法验证开发者”？

macOS 版本没有签名。第一次请在 Finder 里右键应用选“打开”，之后就能正常双击启动。

Live2D 模型从哪里来？

McKuro 不附带模型和 Cubism Core。请从 Live2D 官网下载 Cubism Core，并使用你有权使用的模型文件，在设置页导入即可。

会影响游戏本身吗？

McKuro 只读取游戏目录和日志，按官方启动器的参数启动游戏，不注入、不修改游戏进程。

遇到问题去哪里反馈？

请到 GitHub Issues 提交，附上设置页导出的日志会更快定位。
