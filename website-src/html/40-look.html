窗口跟着系统走

Windows 11 用 Mica，Windows 10 用 Acrylic，macOS 走毛玻璃，Linux 透明背景加应用染色。导航栏是液态玻璃质感，选中项是一枚会滑动的胶囊。

  • 跟随系统材质

    四种原生材质按平台自动选择。

  • 主题即时切换

    跟随系统、浅色或深色，切换立刻生效，不用重启。

  • 动态壁纸

    本地视频，或扫描 Wallpaper Engine 视频壁纸，带封面网格预览。

  • Live2D 模型

    Windows x64 上把 Cubism 模型叠在壁纸之上、内容之下，视线跟随鼠标。Cubism Core 需自行下载，模型由你提供。

四步就能用

  1. 01

    下载并安装

    Windows 用安装包或绿色包，macOS 与 Linux 解压后直接运行。

  2. 02

    指向游戏目录

    选中目录后自动识别渠道，库街区、Bilibili 与 WeGame 都能认出。

  3. 03

    登录一次账号

    短信加应用内极验完成登录，多个接口按手机号判定是否同一账号。

  4. 04

    开始同步

    抽卡、角色与每日数据一键同步，之后每次打开都是最新的。
